# 校园留言分类与垃圾信息识别系统

## 已实现功能

- **用户注册**：创建普通用户账号，支持用户名和密码校验、重复用户名提示。
- **登录与退出**：使用账号密码登录，查看当前登录身份，退出时清理登录会话。
- **角色区分**：区分普通用户和管理员，按角色展示功能入口。
- **登录状态校验**：登录失效时返回登录页，请求失败时显示提示并支持重试。

## 规划功能

- **留言管理**：发布、浏览、搜索和删除留言，查看本人留言及审核结果。
- **垃圾信息识别**：自动区分正常留言与垃圾信息，展示预测结果和分类依据。
- **人工标注与审核**：管理员审核留言、修正分类标签，保留操作历史；审核通过后公开展示。
- **统计看板**：查看留言总量、类别分布和审核状态分布。
- **模型效果比较**：查看分类效果指标，比较初始训练与人工纠正后重训的结果。
